# EEG / sEEG 工作台使用与运维指南

本工作台将一份检查的原始记录、辅助模型、分析参数和计算结果绑定到患者。科学计算使用 MNE-Python 1.12.1，后台以独立进程执行。MNE 1.12 系列支持 Python 3.10 及以上；升级 MNE 时须重新验证文件读取、内部 FIF 引用检查和算法测试，不能仅替换版本号。[MNE 1.12 安装说明](https://mne.tools/1.12/install/manual_install_python.html)

## 1. 开始一份检查

1. 在患者列表打开 **EEG / sEEG 工作台**，确认页首患者和编号。
2. 建立检查，选择头皮 EEG 或颅内 sEEG。不同检查分别保存文件；原有患者附件不会自动导入这套工作台。
3. 上传主记录，必要时再上传配套文件和辅助模型。保留原文件名，成套文件必须属于同一检查。
4. 点击 **读取数据**，检查采样率、通道类型、时长、电极位置和记录标注。文件扩展名正确不代表文件内容一定可以解析。
5. 读取一个时间窗，调整振幅，拖动波形选择分析片段。滚轮移动时间，Ctrl 加滚轮调整振幅；在通道名称区域滚动可切换显示通道。
6. 按需要设置坏道、通道重命名、滤波和参考，再运行频谱、时频、源定位或片段导出。
7. 在任务列表查看进度、失败原因和结果。计算任务保存在数据库，离开页面后仍会执行；排队或运行中的任务可取消。

管理员和工作人员可以上传、提交和取消任务；访客只能查看已有检查、已完成结果和下载。原始文件保留，滤波、参考及坏道处理作用于计算副本，不写回原始记录。

### 原始格式与配套文件

| 格式 | 作为“原始记录”上传 | 作为“配套文件”上传 |
|---|---|---|
| EDF / BDF / GDF | `.edf`、`.bdf`、`.gdf` | 通常不需要 |
| MNE FIF | `.fif`、`.fif.gz` 主文件 | 分卷 FIF；须完整保留文件间引用 |
| BrainVision | `.vhdr` | 被头文件引用的 `.eeg`、`.vmrk` |
| EEGLAB | `.set` | 使用外置数据时需 `.fdt` |
| CNT | `.cnt` | 按文件自身格式需要提供 |

主文件与配套文件分别选择用途。BrainVision 的引用不能指向服务器路径或另一份检查；遗漏配套文件时不会继续读取。EEGLAB 内嵌 `.set` 当前限制为 128 MiB，较大记录应转为 FIF/EDF 或使用分离的 SET/FDT。目录型记录和未列出的格式不属于当前网页上传范围。

同一检查内文件名按大小写不敏感规则保持唯一；不同大小或用途的同名文件会拒绝覆盖。首次完成上传的主记录成为该检查的主文件，上传另一份独立记录时应新建检查。上传使用分块和当前浏览器会话中的续传记录；中断后再次选择同一个文件可尝试续传。

## 2. 通道、参考与分析窗口

波形最多选择 32 个电位通道，一次显示 16 道。刺激标记或其他物理量不能按微伏显示。坏道从分析中排除；重命名必须一一对应且不能生成重复名称。重命名用于匹配模型通道或标准电极名，不会把一个深部接触点变成头皮电极。

滤波频率须低于采样率的一半，高通必须小于低通。当前使用四阶 Butterworth IIR 滤波，并为窗口额外读取有限的边界数据。极短片段或极低高通频率仍可能产生边界影响，应结合原始波形检查。

参考可保留原始参考、计算平均参考，或指定双极导联。双极输入每行写 `阳极通道,阴极通道`，例如 `A1,A2`；所需通道必须包含在所选有效通道中。导出的处理片段使用本次所选通道，不等同于导出整份原始记录。

### EEG 与 sEEG 的适用范围

| 功能 | 头皮 EEG | sEEG |
|---|---|---|
| 波形、坏道、滤波、参考和片段导出 | 支持 | 支持 |
| Welch 频谱、Morlet / Multitaper / Stockwell 时频 | 支持 | 支持 |
| 有正确坐标时显示电极几何 | 支持 | 支持 |
| 本页 14 个标准头皮源定位选项 | 满足模型和参考先决条件时支持 | 禁用 |

sEEG 记录中被读取器标成 EEG 的电位通道会按本次检查类型改为 `seeg`；刺激等非电位通道不因此改型。深部接触点不能改名后套用头皮标准电极位置。MNE 的常规 EEG 正向计算选择头皮 EEG 通道，不能把同样的导体模型直接用于深部电极。颅内源反演需要专门验证的导场、接触点定位、组织导电模型和参考算子，当前工作台没有实现这一流程。[MNE sEEG 教程](https://mne.tools/1.12/auto_tutorials/clinical/20_seeg.html)

## 3. 源定位前必须确认的事项

- **电极位置和模型一致。** 电极名称相同并不能证明它们与上传 Forward 对应；须来自相同检查和几何配准。系统会核对 head 坐标中的电极位置，差异超过 5 mm 时拒绝继续。
- **参考一致。** 标准 EEG 反演使用平均参考投影。不能把双极信号或不匹配的自定义参考直接送入单极头皮 Forward。
- **噪声协方差可解释。** 基线应选没有目标放电、明显伪迹或饱和的可比片段，或提供与本次通道、参考、滤波和单位一致的噪声协方差。系统不能自动证明某段记录是“纯噪声”。
- **模板结果属于探索性估计。** fsaverage 解剖和标准 10–20 电极位置不能代表患者实测解剖及电极位置。球模型明确用于方法演示。
- **审核全部警告。** 重采样、模板位置、通道数量限制、事件丢弃和迭代不收敛都会影响解释。任务完成表示计算完成，不表示结果已经经过临床验证。

头模型分三类：标准 fsaverage 模板、已上传患者模型和演示球模型。头皮 EEG 的 BEM 应具有脑、颅骨、头皮三层；为 MEG 制作的单层 BEM 不适合直接用于 EEG。[MNE EEG 无个体 MRI 教程](https://mne.tools/1.12/auto_tutorials/forward/35_eeg_no_mri.html)

基线起止秒数是相对于记录开头的绝对时间，不能把它们当成事件前后时间。事件时刻同样相对于记录开头；事件窗口的 `tmin`、`tmax` 才是相对于每个事件的时间。多个事件可进行平均，平均次数必须记录为实际使用的事件数。没有填写事件时，使用单个选中窗口，平均次数为 1，不能将它解释为事件平均结果。

### 14 个算法选项

所有方法都要求可用的 EEG 通道。除非提供匹配的噪声文件，否则须选噪声基线。Forward 包含源空间、导场及几何；偶极拟合直接使用导体模型和配准，不以预先上传的 Forward 代替导体模型。

| 页面选项 | MNE 1.12.1 方法 | 主要输入与参数意义 | 输出类型与单位 |
|---|---|---|---|
| MNE | `make_inverse_operator` + `apply_inverse(method="MNE")` | Forward、噪声协方差；正则化 `lambda2=1/SNR²` | 分布式电流矩，A·m |
| dSPM | `apply_inverse(method="dSPM")` | 同上，噪声归一化 | 分布式统计强度，无量纲 |
| sLORETA | `apply_inverse(method="sLORETA")` | 同上，标准化估计 | 分布式标准化强度，无量纲 |
| eLORETA | `apply_inverse(method="eLORETA")` | 同上，迭代求权重；需检查收敛 | 本实现保留电流矩单位 A·m |
| LCMV | `make_lcmv` + `apply_lcmv` | Forward、数据协方差、噪声协方差；`reg` 为协方差正则化 | 本实现归一化幅度，a.u. |
| DICS | `make_dics` + `apply_dics_csd` | Forward、分析频段的交叉谱密度（CSD），可用基线 CSD | 频率／频带源功率，a.u.；不是时间序列 |
| Dipole fitting | `fit_dipole` | EEG、噪声协方差、BEM/球模型和配准 | 偶极位置、方向、幅度 A·m、GOF |
| RAP-MUSIC | `rap_music` | Forward、噪声协方差、指定偶极子数 | 偶极位置、幅度 A·m、整组 GOF |
| TRAP-MUSIC | `trap_music` | 同上，采用截断子空间 | 同上 |
| MxNE | `mixed_norm(n_mxne_iter=1)` | Forward、噪声协方差；稀疏惩罚 α | 稀疏电流矩，A·m |
| irMxNE | `mixed_norm(n_mxne_iter>1)` | 同上，有限次迭代重加权 | 稀疏电流矩，A·m |
| TF-MxNE | `tf_mixed_norm(n_tfmxne_iter=1)` | 同上，时频稀疏约束；窗口须足够长 | 稀疏电流矩，A·m |
| irTF-MxNE | `tf_mixed_norm(n_tfmxne_iter>1)` | 同上，有限次时频重加权 | 稀疏电流矩，A·m |
| Gamma-MAP | `gamma_map` | Forward、噪声协方差；独立的噪声方差正则化 α | 稀疏电流矩，A·m |

MxNE 与 TF-MxNE 的 α 是稀疏正则化强度，范围为 `[0,100)`；Gamma-MAP 的 α 是噪声方差正则化参数，含义不同，页面使用单独输入框。SNR 是正则化假设，不是系统实测的信噪比。`reg` 主要用于波束形成，偶极子数主要用于 RAP/TRAP-MUSIC，不是所有算法通用的“源个数”。

DICS 当前将所选频带的 CSD 合并后估计平均功率；显示频率为频带代表值，不是频谱主峰，也不是峰值出现秒数。其他方法的时间列由 `temporal_reference` 区分：`recording_absolute` 从记录开头计秒，`event_relative` 以事件触发为零。RAP/TRAP-MUSIC 的 GOF 是整组模型对数据的拟合优度，不是每个位置的独立可信度。不同算法的数值尺度不同，不能用原始峰值大小横向排名。三维暖色点在当前结果内归一化，用于显示相对强弱。

上述选项覆盖工作台公开的主要反演方法及迭代变体，不表示实现了 MNE 的所有函数、参数或分析流程。[MNE 反演 API](https://mne.tools/1.12/api/inverse.html)、[最小范数](https://mne.tools/1.12/generated/mne.minimum_norm.apply_inverse.html)、[LCMV](https://mne.tools/1.12/generated/mne.beamformer.make_lcmv.html)、[DICS](https://mne.tools/1.12/generated/mne.beamformer.apply_dics_csd.html)、[MxNE](https://mne.tools/1.12/generated/mne.inverse_sparse.mixed_norm.html)、[TF-MxNE](https://mne.tools/1.12/generated/mne.inverse_sparse.tf_mixed_norm.html)、[Gamma-MAP](https://mne.tools/1.12/generated/mne.inverse_sparse.gamma_map.html)

### 结果、MRI 与可追溯性

时频结果可选择单个通道查看并放大，同时保留通道平均图及 NPZ 数值。源定位导出 NPZ、CSV 和 PNG；三维结果支持旋转、缩放。处理记录包含 MNE/NumPy 版本、实际通道和采样率、参考、重采样及窗口等信息，源定位还保存试次数、噪声模型、坐标系和时间轴。

源点统一输出 head 坐标，单位为米，不冒充 MNI 坐标。MRI 图像先转换为规范 RAS 方向，再生成矢状、冠状、轴位切片，定位点同步变换。缓存 fsaverage 解剖及配准已知匹配，可以叠加定位点；普通上传 MRI 不会自动获得配准，只显示结构像中央切片并说明未叠加源点。上传 MRI 不能替代 BEM、源空间及正确的 MRI/head 变换。

## 4. 与 BESA 等桌面工具的关系

工作台提供患者绑定的文件管理、波形浏览、有限预处理、频谱／时频、上述源定位和结果下载。它没有宣称 BESA 的完整功能、专有算法、项目格式、参数或工作流兼容性；也不因使用同名算法而获得相同实现或验证结论。

目前没有 BESA 专有项目读取、完整手工伪迹审阅／校正流程、个体 MRI 分割与交互式配准向导、颅内导场建模，或与商业医疗软件等同的认证承诺。MRI 文件上传本身不会自动生成患者 BEM 和源空间。工作台显示的源峰值不能单独用于确定致痫区或手术范围。

## 5. 运维与资源限制

### 后台进程和私有存储

Web 请求只负责记录和排队；科学进程不运行在 Django 请求线程内。`preview` 队列处理读取数据／波形，`analysis` 队列处理其他分析。每条队列仅一个工作进程持锁执行，一条队列同时计算一项，两个队列可以并行。BLAS、OpenMP 等计算线程限制为 1。

在项目目录、使用项目虚拟环境及正确 Django 设置启动：

```text
python manage.py eeg_worker --lane preview
python manage.py eeg_worker --lane analysis
```

云部署服务模板为 `deploy/cloud/epilepsy-eeg@.service`，对应 `epilepsy-eeg@preview.service` 和 `epilepsy-eeg@analysis.service`。云端命令使用 `epilepsy_portal.settings.cloud`。服务模板存在不代表实例已经安装或启用；部署后应分别检查实例状态和实际资源配置。

云端约定私有数据目录 `/var/lib/epilepsy-portal/eeg`，模板位于其 `subjects/fsaverage` 子目录。一般部署使用 `EEG_STORAGE_ROOT` 指定私有根目录，`EEG_SUBJECTS_DIR` 指定 FreeSurfer subjects 目录。它们必须在公开媒体和静态目录之外；下载通过已登录、带角色检查的接口完成。

备份须同时覆盖数据库和 EEG 私有文件／成果目录，不能只复制数据库。任务参数、上传文件 SHA-256 和成果是追溯计算的组成部分。不要把计算输入、私有工作日志或患者文件放入公开静态目录。

### fsaverage 模板准备

安装阶段可显式下载公开模板并预生成三层 ico3 BEM、ico4 源空间：

```text
python deploy/cloud/prepare-eeg-template.py /var/lib/epilepsy-portal/eeg/subjects --download
```

不带 `--download` 时只使用已有模板。患者分析任务不会自动下载模板或发送患者数据。模板文件需由计算服务用户读取；准备失败时检查目录、网络和依赖，再明确重试。

### 默认上限

| 项目 | 当前默认限制 |
|---|---|
| 单个上传文件 | 1 GiB |
| 同一患者工作台上传总量 | 5 GiB，包含辅助文件及已登记未完成上传 |
| 同一患者排队／运行任务 | 合计最多 4 项 |
| 页面显示通道选择 | 最多 32 道；画布一次显示 16 道 |
| 源分析通道 | 最多 128 道，超限处理须查看警告 |
| 非源分析片段 | 最多 120 秒 |
| 单窗源分析／单个事件窗口 | 最多 10 秒 |
| 同次源分析事件 | 最多 200 个 |
| 包含基线、事件及边界的读取跨度 | 最多 300 秒，并受 8,000,000 个通道×采样点限制 |
| 单项任务运行时限 | 默认 900 秒 |
| 预览／分析子进程虚拟地址空间 | 默认 2 GiB／5 GiB（Linux `RLIMIT_AS`） |
| 单个输出文件 | 默认 512 MiB（Linux 文件大小限制） |
| 开始上传／开始计算的磁盘余量 | 默认保留 2 GiB／1 GiB |

源分析默认将高采样率数据经抗混叠重采样降至最高 250 Hz，以降低资源消耗；这是计算副本的变化，原始记录不变。相关参数与警告必须随结果保留。任务超时、取消或进程异常结束不会标记为成功。

systemd `MemoryMax` 是服务控制组的内存限制，与子进程 `RLIMIT_AS` 不是同一指标。服务模板默认 `MemoryMax=4G`、`CPUQuota=200%`；部署时为云端预览实例使用更小的 1500M／100% 覆盖，分析实例使用 4G／200%。应检查实际 drop-in 和 `systemctl show` 的生效值，不能把模板值当作实时用量或可用物理内存。

服务启动或重启时会把中断任务标记为失败／取消，不会悄悄当作已完成。长时间排队时先检查两个 worker 实例；运行失败时检查页面错误和管理员可访问的私有日志。先缩短窗口、减少通道或避开高成本算法，再检查模型及参数；不要通过无限增大限制掩盖输入问题。
