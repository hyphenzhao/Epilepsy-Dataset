Derived with fontTools 4.65.0 in a separate build environment:
- Static weight 400 for Regular and weight 700 for Bold.
- Oblique outlines use a horizontal shear of 0.20, with matching italic
  metadata. BoldOblique combines weight 700 and the same shear.
- Family and PostScript names were changed to Report Sans SC / ReportSansSC.
- The original full character map is retained. ReportLab embeds and subsets
  the characters actually used in each exported PDF.

FontTools is a build tool and is not required by the deployed application.
